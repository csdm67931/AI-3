MODULE 04 / Markdown

檔案格式 = 你的記憶壽命

封閉格式

  • Word (.docx) — 鎖在微軟
  • Notion — 鎖在公司伺服器
  • PDF — 死的、不易編輯
  • 截圖 — AI 讀得辛苦
  • Evernote — 老牌但封閉

公司倒了？平台改規則？
你的筆記跟著一起死。

vs

Markdown (.md)

  • 純文字檔，永遠能開
  • 跨工具、跨平台、跨 AI
  • LLM 原生最愛吃的格式
  • 容易版本控制（Git）
  • 容易全文搜尋

30 年後你的孫子
都還能打開。

MODULE 04 / Markdown

Markdown 看起來像這樣


# 我的第一篇筆記

## 重點
- **粗體** 跟 *斜體* 都很簡單
- 用 `-` 就是清單
- 用 `#` 就是標題

## 連結
- 連到別篇筆記：[[Claude_Desktop_MCP_設定]]
- 連到網頁：[Anthropic](https://anthropic.com)

## 標籤
#AI #第二大腦 #2026

> 引言用大於符號開頭

就這些。學會這 5 個符號，你能用一輩子。

MODULE 07

我的真實用法核心

MODULE 07 / 用法 #1

用法一：拆解過去寫過的程式

做法

  • 把舊程式 import 進 vault
  • 請 Claude 拆出每個函數的功能
  • 標籤分類：#訊號 #風控 #繪圖
  • 建立 MOC（Map of Content）

累積效果

  • 下次新專案，直接從 vault 找模組
  • AI 知道我的程式風格
  • 客戶問「能不能加 XX 功能」
    → 找出舊版本 → 改寫
  • 3 天 → 30 分鐘
場域對照用法一： - 學生：「拆解過去寫過的報告」 - 社會人士：「拆解過去做過的提案」 - 創作者：「拆解過去寫過的文章」
MODULE 07 / 用法 #2

用法二：讀書不再消失

做法

  • 每本書建一個 MOC
  • 章節重點分篇寫成獨立 note
  • 連結到「我能用的場景」
  • 例：《遊戲化實戰》→ 八角框架 → 套用在客戶服務

累積效果

  • 讀過的書變成你的，不是書架上的
  • 寫文章時 Claude 自動找到相關片段
  • 不同書的概念開始互相連結
  • 長出你自己的觀點
MODULE 07 / 用法 #3

用法三：每日累積（Daily Note）

做法

  • 每天開一篇 daily note
  • 記三件事：學到 / 做了 / 想到
  • 關鍵句加 [[雙向連結]]
  • 重要 AI 對話 → 複製進 vault

累積效果

  • 一年後有 365 個錨點
  • 每個錨點都連到 vault 其他地方
  • 你會「看見自己的成長」
  • 履歷、自傳、年終，素材都在裡面
MODULE 08 / 進階：HANDOFF 模式可選

進階心法：HANDOFF Note

每次跟 AI 的長對話結束時，請 AI 寫一份「交接筆記」存進 vault：


# HANDOFF_2026-05-13_1800_evocode-api-lint

## 我們討論了什麼
討論 EvoCode API 介面命名一致性問題

## 結論
- 統一用 snake_case
- ToolBelt 模組需要重構

## 下次接著做
- 重構 TradeApi_CustomColumns
- 驗證向後相容性

## 相關連結
- [[EvoCode_TradeApi]]
- [[TradeApi_History]]

下次任何 AI（Claude / GPT / Gemini）都能秒接得上。
再也不會「上次討論到哪了？」。
