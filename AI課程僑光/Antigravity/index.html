MODULE 03 / 三層架構

從卡片盒筆記 (Zettelkasten) 到 2024 AI 原生世代：

① 載體 (Format)

Markdown

純文字、可攜帶、AI 最好讀的格式。

② 容器 (Container)

Obsidian

本地檔案、雙向連結、強大外掛生態。

③ 串接 (Connect)

Claude + MCP

讓 AI 直接讀取、分析、寫入你的知識庫。

MODULE 04 / 載體

為什麼是 Markdown？

封閉格式

  • Word (.docx)
  • Notion (雲端)
  • PDF / 圖片截圖

AI 難以直接解析，或容易被平台綁架。

VS

Markdown (.md)

  • 純文字，30 年後還能開
  • 語法極簡 (5個符號就夠)
  • AI 原生最愛的格式

跨平台：Obsidian / VS Code / 記事本 都能開。

MODULE 05 / 容器

為什麼是 Obsidian？

  • Notion / Evernote： 雲端封閉、資料不完全屬於你。
  • Obsidian： 本地 .md 檔案、免費、視覺化 Graph、外掛生態系。
